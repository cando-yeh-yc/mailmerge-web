隱私政策

最後更新：2026/07/25

一句話版本：本工具不收集、不儲存、不傳輸您的任何內容資料。沒有伺服器、沒有資料庫；僅使用無 Cookie 的匿名流量統計（見下方「Cookie 與流量統計」）。

我們如何處理資料

  • 登入憑證（token）：透過 Google／Microsoft 官方 OAuth 流程取得，只保存在您瀏覽器的記憶體中，關閉分頁即消失。您的密碼從頭到尾只輸入在 Google／Microsoft 的官方頁面。
  • 收件人名單、信件模板、附件：只存在您瀏覽器的記憶體中，不會上傳到任何伺服器。
  • 信件寄送：由您的瀏覽器直接連線 Gmail API 或 Microsoft Graph API 寄出，不經過任何中介伺服器。寄出的信保存在您自己信箱的寄件備份。

權限範圍（Scopes）

  • Google：gmail.send（僅代為寄信）、email（顯示登入帳號）。不要求讀取信件、通訊錄或雲端硬碟的權限。
  • Microsoft：Mail.Send（僅代為寄信）。

本應用程式對 Google API 取得之資訊的使用，遵守 Google API Services User Data Policy（含 Limited Use 要求）。

Cookie 與流量統計

本工具不使用 Cookie、不嵌入任何廣告追蹤程式。網站流量統計採用 Cloudflare Web Analytics：無 Cookie、不建立個人檔案、不做跨網站追蹤，僅產生匿名的彙總數據（如頁面瀏覽次數、來源、瀏覽器類型），無法識別任何個人身分。您的名單、信件內容與 Google／Microsoft 帳號資料完全不會進入流量統計。

資料刪除

因為我們不儲存任何資料，沒有需要刪除的東西。關閉分頁即清空一切；您也可以隨時在 Google／Microsoft 帳號設定中撤銷本應用程式的授權。

Privacy Policy (English)

This policy applies to 客製郵件群發 Mail Merge (https://mailmerge-web.ycfinance.tw/), built and operated by Cando Yeh.

In one sentence: this tool does not collect, store, or transmit any of your content data. There is no server and no database; the only measurement is cookieless, anonymous traffic statistics (see below).

  • OAuth tokens are obtained via the official Google / Microsoft OAuth flows and kept only in your browser's memory; they vanish when the tab is closed. Your password is only ever entered on Google's / Microsoft's own pages.
  • Recipient lists, email templates, and attachments exist only in your browser's memory and are never uploaded anywhere.
  • Sending happens directly from your browser to the Gmail API / Microsoft Graph API with no intermediary server. Sent messages appear in your own Sent folder.
  • Scopes: Google gmail.send (send only) and email (display the signed-in account); Microsoft Mail.Send. We never request read access to your mailbox, contacts, or files.
  • This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Traffic statistics: we use Cloudflare Web Analytics — cookieless and anonymous. It produces aggregate metrics only (page views, referrers, browser type), sets no cookies, builds no user profiles, and does no cross-site tracking. Your recipient lists, message content, and Google / Microsoft account data never enter these statistics.
  • No cookies, no ad tracking. Since none of your content is stored, there is nothing to delete — close the tab and everything is gone. You can revoke access anytime in your Google / Microsoft account settings.
